Bluetooth Battery Tray 1.0.0
============================

Показывает заряд подключённых Bluetooth-устройств прямо в системном трее.
Работает с BLE-устройствами и с классическими (гарнитуры/наушники HFP).

Требования
----------
- Windows 10 или Windows 11 (64-bit)
- Включённый Bluetooth-адаптер
- Administrator-права не нужны

Запуск
------
Запустите BluetoothBatteryTray.exe. В трее появятся значки подключённых
устройств. Если ни одно устройство не подключено, остаётся один нейтральный
значок, чтобы можно было открыть меню и выйти.

Управление
----------
- Двойной клик по значку        — список устройств
- Правый клик по значку         — меню (Show Devices..., Refresh Now, Exit)
- Кнопка Refresh в списке       — принудительное обновление
- Set Image / Clear Image       — своя картинка для устройства в трее

Плитка с картинкой рисуется над полосой заряда. Картинка привязывается к
MAC-адресу устройства, поэтому переживает переподключение и перезапуск.

Значки и закрепление в трее
---------------------------
Иконка каждого устройства имеет постоянный идентификатор. Если один раз
закрепить её в панели задач Windows ("Параметры панели задач" -> "Другие
значки приложений"), она будет возвращаться на то же место после
переподключения, а не уезжать в скрытые.

Автозапуск
----------
При установке можно включить "Запускать при входе в Windows". При portable-
запуске автозапуск не настраивается: при необходимости добавьте ярлык
BluetoothBatteryTray.exe в папку автозагрузки вручную.

Где хранятся настройки
----------------------
- HKCU\Software\BluetoothBatteryTray\DeviceIcons — пути к картинкам
- HKCU\Software\BluetoothBatteryTray\TrayIds     — постоянные ID иконок
- %LOCALAPPDATA%\BluetoothBatteryTray\icons      — копии картинок

Установщик удаляет эти данные при деинсталляции.

Удаление
--------
"Параметры" -> "Приложения" -> "Bluetooth Battery Tray" -> "Удалить",
либо ярлык Uninstall в меню "Пуск".
